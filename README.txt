HOME CASH POKER TRAINER — v1

Game assumptions: full ring; $0.10/$0.20 blinds; $20 initial buy-in (100 BB); no rake; no top-ups while still in the game; unlimited $20 rebuys after busting.

Included:
- Mobile-first training interface for Android browsers
- 15 authored scenario examples
- Scenario choices and explanatory feedback
- Local progress/history saved in the browser
- PWA manifest and service worker for installation/offline caching after first visit

IMPORTANT:
This is a working prototype, not a solver. Its "best training action" is an authored teaching target, not a claim of exact GTO. A few spots have close or configuration-dependent decisions. Do not treat the score as a measure of win rate.

HOW TO USE ON ANDROID:
1. Host the contents of this folder on an HTTPS static host (e.g. GitHub Pages or Netlify).
2. Open the HTTPS site in Chrome on Android.
3. Use Chrome menu (⋮) > Add to Home screen or Install app, if offered.
4. Progress is saved in that browser on that device. Clearing browser data may remove it.

To test locally on a computer, open index.html in a browser. PWA installation/offline features require HTTPS or localhost.
